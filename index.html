Vulnerability Prioritization Assistant

Scanners tell you what is broken. We tell you what to fix first, and why.

Overview Documents Backlog Demo Team

Overview

Security scanners produce thousands of findings, but teams can fix only a few each week, and a CVSS score alone does not show which ones matter. Our tool merges the output of several scanners, adds real-world danger signals from free public sources (CISA KEV, EPSS, NVD), and combines them with context about each asset into a ranked to-do list. Every item in the list comes with a plain explanation and a suggested fix.

  • Reader: converts scanner output (Trivy first, then Nmap) into one common format.
  • Enricher: adds exploitation evidence and likelihood data from public sources.
  • Scorer: combines severity, exploit evidence, and asset context into a priority score and records the reason.
  • Interface: shows the explained ranked list next to a plain CVSS ranking.

Course: CMPE 491 Senior Design Project I, TED University, Fall 2026.
